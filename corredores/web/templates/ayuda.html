Cómo se lee ESecureBroker

Sin jerga: qué es captura, qué es una vista, y qué hace cada pantalla.

Términos que más confunden

Captura
Escribir una vez los datos del riesgo (auto, cliente, uso…). No es “sacar foto”: es el formulario del Cotizador.
Vista
Cómo se muestra la información en una pantalla (Hoy, Radar, tabla de cobranza, 360°…). La vista no inventa datos.
Orquestador de cotización
El sistema pide precio a varias compañías: por API, por archivo, o tú cargas la respuesta a mano.
Comparador
Una sola tabla con todas las respuestas ya en el mismo formato. Ahí eliges tú; la IA solo explica.
Dominio
La verdad en base de datos (póliza, cuota, pago, vigencia). La UI solo la enseña.
NBA / IA
Sugerencia con porqué. Tú aceptas, descartas o pospones. No cambia saldos ni primas.

Cotizador en 5 pasos

  1. Captura — ¿qué se cotiza?
  2. Aseguradoras — ¿a quiénes les pido?
  3. Orquestador — el sistema sale a pedir
  4. Normalizar — mismo formato
  5. Comparar — tabla → IA explica → tú decides

Cobranza — 5 bandas (nombres humanos)

  • Rutinario el sistema lo lleva solo
  • Intervenir necesitas llamar o actuar
  • Promesa el cliente prometió pagar
  • Promesa rota no cumplió la promesa
  • Excepción caso especial

“Vence hoy / atrasados / aging” son filtros o columnas — no sustituyen estas bandas.
